## Professional Experience Portfolio website

Minimal [Quarto](https://quarto.org/) website scaffold for GitHub Pages.

```
├─portfolio-repo
├── .github/workflows - Automatic publishing machinery
├── images            - Place all images for posts in here
│    └── headshot.png
├── LICENCE           - You should include a licence appropriate for your project
├── README.md         - Appears on your GitHub repository page
├── about.qmd         - Should contain info about you and your work
└── index.qmd         - The main page of your website
```

The workflow renders the site and deploys it to GitHub Pages using a GitHub Actions workflow.
